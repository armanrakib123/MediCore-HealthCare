🏥 MediCore | Smart Prescription Tracker
SLT Internship Sample Project - User Manual
===========================================

📌 Project Summary
------------------
MediCore is a multi-role healthcare platform built by the Smart Prescription Tracker team.
Main roles: Patient, Doctor, Pharmacist, Admin.


📁 Folder Structure (Important)
-------------------------------
smart-rx-frontend/
├── src/                          -> React frontend source code
│   ├── pages/                    -> Dashboards & main screens
│   ├── components/               -> Reusable UI components
│   ├── api/                      -> Axios API client and endpoints
│   └── hooks/, utils/            -> Shared logic/helpers
├── public/                       -> Static assets
├── MediCore.API/           -> ASP.NET Core backend API
│   ├── Controllers/              -> API endpoints
│   ├── Services/                 -> Business logic
│   ├── Repositories/             -> Data layer
│   ├── Models/                   -> MongoDB models
│   └── DTOs/                     -> Request/response contracts
├── package.json                  -> Frontend scripts/dependencies
├── smart-rx-frontend.sln         -> .NET solution
└── README.md


✅ Prerequisites
----------------
1) Node.js 20.19+ (or 22.12+)
2) npm
3) .NET SDK 10
4) MongoDB running locally or remote


🚀 How to Run the Project
-------------------------
1) Run Backend API
   - Open terminal:
     cd /Users/ravindupiyumal/Desktop/newhealthcare/smart-rx-frontend/MediCore.API
     dotnet restore
     dotnet run

   - Backend URL:
     http://localhost:5000

2) Run Frontend
   - Open another terminal:
     cd /Users/ravindupiyumal/Desktop/newhealthcare/smart-rx-frontend
     npm install
     npm run dev

   - Frontend URL:
     https://medicore-healthcare-seven.vercel.app

3) API Base URL (if needed)
   - In frontend .env file set:
     VITE_API_BASE=http://localhost:5000


🔐 Login Methods
----------------
A) Normal Login
   - Go to: https://medicore-healthcare-seven.vercel.app/auth
   - Select your role and login with email/username + password.

B) Google Login
   - On Login page, click Google sign-in.
   - Complete Google account popup/consent.
   - System calls /api/auth/login-google and logs user in.

   Notes:
   - Internet connection is required.
   - Browser popup blocking should be disabled for localhost.

🛠️ Troubleshooting
-------------------
- "vite: command not found"
  -> Run npm install in smart-rx-frontend folder.

- Backend not starting
  -> Ensure MongoDB is running and port 5000 is free.

- Google login not opening
  -> Allow popups and check internet/network restrictions.
